## Featured work — HalıWork

HalıWork brings customer management, orders, payment collection, deliveries, and field operations into one platform.

- **Backend:** C# / ASP.NET Core Web API, Entity Framework Core, PostgreSQL, and Redis.
- **Application architecture:** multi-tenant workflows, JWT authentication, and background jobs.
- **Mobile & web:** a React Native mobile application and a Next.js administration panel.
- **Integrations:** SMS, notifications, maps, and label printing.
- **Production:** Linux / Nginx deployments, service management, logging, backups, and troubleshooting.

I work across these components and use feedback from real customers to guide product improvements. Development began in **August 2025**; the company was established in **January 2026**.
